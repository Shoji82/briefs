# Cursor Privacy Mode, and training

4 October 2026. Maya accepted this research on 4 October 2026. This note does not state one default for the Teams plan.

## When Privacy Mode is on

https://cursor.com/help/security-and-privacy/privacy says Privacy Mode ensures code is never used for training by Cursor or other AI model providers. Prompts and code context are still sent to providers such as OpenAI, Anthropic, and Google. With Privacy Mode enabled, code is not used for training.

https://cursor.com/data-use (3 September 2026): if Privacy Mode is on, Customer Data will not be used for training by Cursor, and providers will not store or train on it. If it is turned off, Cursor may store codebase data, prompts, editor actions, and code snippets and train its models. That page does not say whether it starts on, and it does not name a plan.

https://cursor.com/privacy (29 September 2026): Inputs and Suggestions are not used to train models, and third parties are not permitted to use them for training, unless they are flagged for security review, the user explicitly reports them, or the user has explicitly agreed. This policy does not apply where Cursor processes data for a commercial customer, such as an employer-provisioned account. The page does not name Privacy Mode, or Hobby, Pro, Pro+, Ultra, Teams, or Enterprise.

https://cursor.com/terms-of-service (3 September 2026): Cursor will not use content to train, or allow a third party to train, unless the user has explicitly agreed. It does not mention Privacy Mode. https://cursor.com/terms returned 404.

## Open conflicts

On https://cursor.com/help/security-and-privacy/privacy, one sentence says: "For teams, Privacy Mode is enabled by default for all team members." Later on the same page it says Privacy Mode is on by default for Enterprise teams, and that Teams and Enterprise admins can enforce it so members cannot disable it. That second sentence does not say the Teams plan is on by default. This note does not pick a winner.

https://cursor.com/docs/enterprise/privacy-and-data-governance and https://cursor.com/docs/enterprise/security-hardening say on by default for Enterprise. https://cursor.com/docs/enterprise labels Privacy Mode "User choice" for individual plans and "Enforce org-wide" for Teams and for Enterprise. That table does not say on by default. These pages do not say the Teams plan is on by default.

These pages say Privacy Mode can be enabled or enforced, and they are silent on the Teams default: https://cursor.com/security (25 August 2026), https://cursor.com/pricing, https://cursor.com/docs/account/teams/pricing, and https://cursor.com/docs/account/teams/dashboard. Pricing names Hobby, Pro, Pro+, and Ultra, but it does not say whether Privacy Mode is on for them.

## A limit, not a default

Some models, Claude Fable 5 and 5.1, store inputs and outputs for harm-prevention review, and that data is not used for training. They need approval for Enterprise customers, Teams with Privacy Mode enabled, and individual customers with Privacy Mode enabled. Source: https://cursor.com/docs/enterprise/privacy-and-data-governance. A personal account might not have Privacy Mode enabled. That is not a sentence that individual plans are off by default.

This note does not recommend a plan.
